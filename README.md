# CRACK

CRACK — subastas futboleras a ciegas.

## Ejecutar en local

```bash
npm install
npm run dev
```

## Publicar en Vercel

```bash
npx vercel --prod
```

## Estado del catálogo

- Se retiró a Nicklas Bendtner del juego.
